# 쇼핑몰 고객 분석 및 단골 고객 찾기

## 프로젝트 개요 (Project Overview)

이커머스 멀티모달 데이터 분석과 RFM 기반 고객 세분화를 통한 단골 고객 발굴 및 비즈니스 전략을 도출하는 프로젝트

## 프로젝트 구조 (Project Structure)

```text
.
├── data/
│   ├── transactions.csv         # 온라인 주문 상품 내역
│   ├── images/                  # 상품 사진 22장 (GIF)
│   └── source.txt               # 원본 출처와 추출 범위
├── docs/
│   ├── data.md                  # 데이터 설명과 표본 선정 기준
│   ├── data-license.txt         # Microsoft 원본 라이선스
│   ├── run.md                   # 환경 설정과 실행 방법
│   ├── insights.md              # 고객군별 비즈니스 인사이트
│   ├── segments.html            # 인터랙티브 RFM 차트
│   ├── cohort.md                # 첫 구매월별 재구매율 분석
│   └── cohort-heatmap.png       # 월차별 재구매율 히트맵
├── notebooks/
│   └── analysis_report.ipynb    # 실행 결과를 담은 분석 노트북
├── src/
│   └── pipeline.py              # DataAnalyzer 분석 클래스
└── README.md                    # 프로젝트 개요, 체크리스트, 결과물 링크
```

## 제약 사항 (Constraints)

- Python 3.8 이상 사용
- 허용 라이브러리: NumPy, Pandas, Matplotlib, Seaborn
- 보너스 인터랙티브 시각화에 한하여 Plotly 사용 허용
- OpenCV, Pillow 등 이미지 처리 전용 라이브러리 사용 금지
- Scikit-learn, NLTK 등 머신러닝·자연어 처리 라이브러리 사용 금지
- `pandas-profiling`, `sweetviz` 등 자동 EDA 라이브러리 사용 금지
- 이미지 피처는 NumPy 배열 연산으로 직접 계산
- 이미지 입력은 `imread()` 사용 가능하며, 반환된 NumPy 배열을 직접 조작
- CSV에 문자열로 저장된 배열은 `numpy.fromstring()` 또는 `ast.literal_eval()`로 복구 가능
- 이미지 리사이즈는 `arr[::n, ::n]` 형태의 NumPy 슬라이싱으로 단순 다운샘플링 가능
- 데이터 출처를 반드시 명시하고 라이선스 이용 조건 준수
